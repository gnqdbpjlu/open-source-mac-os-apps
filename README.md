# Open-Source MacOS Apps

A curated list of open-source macOS apps. Contributions are welcome!

## How to Contribute

- Fork the repo
- Add your app to the list
- Submit a pull request

## Apps

- [Amethyst](https://github.com/ianyh/Amethyst) - Tiling window manager
- [CotEditor](https://github.com/coteditor/CotEditor) - Lightweight text editor
- [iTerm2](https://github.com/gnachman/iTerm2) - Terminal emulator
