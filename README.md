# Open-Source macOS Apps

A curated list of open-source macOS applications. Contributions welcome!

## How to Contribute

1. Fork this repository.
2. Add your app to the list (alphabetical order).
3. Ensure the app is open-source and actively maintained.
4. Submit a pull request.

## Apps

- **Amphetamine** – Keep your Mac awake. [Link](https://github.com/xiaozi/amphetamine)
- **iTerm2** – A terminal emulator. [Link](https://github.com/gnachman/iTerm2)
- **Rectangle** – Window management. [Link](https://github.com/rxhanson/Rectangle)
