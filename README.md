## Audio

* [LyricsFinder](https://github.com/ddelange/LyricsFinder) - macOS menu bar app for lyrics. `Swift`!

## Developer Tools

* [Iconizer](https://github.com/raphaelhanneken/iconizer) - Create Xcode image sets and app icons. `Swift`!
* [DevCleaner](https://github.com/vashpan/DevCleaner) - Reclaim space used by Xcode cache files. `Swift`!

## Utilities

* [Maccy](https://github.com/p0deje/Maccy) - Lightweight clipboard manager for macOS. `Swift`!
* [Stats](https://github.com/exelban/stats) - macOS system monitor in menu bar. `Swift`!
